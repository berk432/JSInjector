# JavaScript Otomatik Injector

CustomTkinter ile yapılmış, Selenium kullanarak web sitelerine otomatik JavaScript enjekte eden araç.

## Özellikler

- Tek tıkla JS enjekte etme
- Modern koyu tema arayüz
- Detaylı debug/hata takip alanı
- Tarayıcı otomatik kapanmaz
- Aynı tarayıcıyı tekrar kullanma
